# Guides

Task-based documentation, organized by who you are and what you're trying to do. Start here if you want to **use**, **administer**, **operate**, or **build on** Cinatra. For stable specifications and architecture see [References](../references/README.md); for positioning and evaluation see [Resources](../resources/README.md).

- [User Guide](user/README.md) — running agents, chat, human-in-the-loop (HITL) review, dashboards, skills, and cross-instance collaboration
- [Admin Guide](admin/README.md) — the `/configuration/*` area: marketplace, extensions, permissions, providers, telemetry, and instance settings
- [Developer Guide](developer/README.md) — authoring agents and extensions, the contributor workflow, and the day-to-day developer loop
- [Hosting Guide](hosting/README.md) — installation, configuration, and troubleshooting; what an operator needs to know

New to Cinatra? Run your first agent with the [Quickstart](hosting/quickstart.md).
